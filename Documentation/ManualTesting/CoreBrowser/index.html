Photon core browser test suite

Use the same pages and actions in Photon and a reference browser (Safari, Firefox, or Chrome). Mark a case as pass/fail in your notes and record the browser version, OS, Photon build, and any console/error messages.

Start here: Open this index.html in both browsers. Use its links to move between pages. The files are self-contained and do not need a server. The storage case uses browser storage scoped to this local file origin; if the browser blocks it, serve this folder over localhost and repeat.

Core functionality checklist

App and navigation

  • Launch, new tab, close tab, reopen closed tab
  • Address entry: explicit URL, bare domain, localhost, search query
  • Back/forward, reload, stop loading, redirect
  • Link target behavior, external links, popup/new window
  • Page title and favicon updates

Page interaction

  • Text selection, copy/paste, keyboard shortcuts
  • Forms, validation, autofill behavior
  • Find in page, zoom, scrolling, focus
  • Images, audio/video, SVG, canvas, fonts
  • Context menu and mouse back/forward

State and privacy

  • Cookies and site storage survive reload/restart
  • History, search suggestions, clear browsing data
  • Downloads, permission prompts, pop-up policy
  • Private/temporary profile behavior (if available)
  • Crash/recovery and session restore

Stability and compatibility

  • Repeated tab creation, navigation, and close
  • Large/long page, many images, animated content
  • Resize window, switch tabs while loading
  • HTTPS, certificate errors, mixed content
  • Compare layout and interaction on same viewport
