# `photon-app`

The executable entry point for the Photon browser. It starts the `photon-shell` application and is built by the repository's `photon` command.

## Run

From the repository root:

```sh
photon setup
photon run
```

Use [`photon-cli`](../photon-cli/README.md) for the development commands and [`photon-shell`](../photon-shell/README.md) for the native browser window implementation.
